# 17 — Training Task Tracker

A SwiftUI mini-project to track training modules and completion progress.

## Features to build
- List training modules and tasks
- Mark tasks as pending, in progress, or completed
- Show completed count and progress percentage
- Filter tasks by status
- Persist task state as a follow-up improvement

## Suggested build sequence
1. Create a SwiftUI app in Xcode.
2. Define a `TrainingTask` model.
3. Display tasks in a List.
4. Add controls to update completion state.
5. Show a progress summary.
6. Test in the iOS Simulator.
