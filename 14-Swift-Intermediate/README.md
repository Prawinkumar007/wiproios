# 14 — Swift Intermediate

## Suggested learning areas
- Properties: observers, lazy, computed, and static
- Access control and initialization
- Subscripts and property wrappers
- Protocol-oriented programming and delegation
- Enumerations with associated values
- Advanced error handling and Result

- Memory ownership and value semantics
