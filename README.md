# Wipro iOS Training

A structured learning repository for the Wipro iOS training journey. Each numbered folder contains focused notes, Swift examples, exercises, and progress records.

## Learning roadmap

| Folder | Focus |
|---|---|
| [01-Swift-Fundamentals](01-Swift-Fundamentals/) | Swift syntax, variables, constants, operators |
| [02-Collections](02-Collections/) | Arrays, Sets, Dictionaries |
| [03-Enums-Structs-Classes](03-Enums-Structs-Classes/) | Enumerations, value types, reference types |
| [04-Optionals-ARC](04-Optionals-ARC/) | Optionals, ARC, memory management |
| [05-Functions-Closures](05-Functions-Closures/) | Functions, closures, higher-order functions |
| [06-Protocols-Generics-Errors](06-Protocols-Generics-Errors/) | Protocols, extensions, generics, error handling |
| [07-Daily-Learning-Log](07-Daily-Learning-Log/) | Daily learning notes and reflections |
| [08-Practice-Tasks](08-Practice-Tasks/) | Coding practice and task checklist |
| [14-Swift-Intermediate](14-Swift-Intermediate/) | Intermediate Swift concepts and patterns |
| [15-SwiftUI-Basics](15-SwiftUI-Basics/) | SwiftUI views, state, and navigation |
| [16-Next-Topics](16-Next-Topics/) | Upcoming topics and learning checklist |
| [17-Training-Task-Tracker](17-Training-Task-Tracker/) | Training task tracker project |

## How to use

1. Open a topic folder.
2. Read its README for the learning objectives.
3. Run the Swift examples in Xcode or a Swift Playground.
4. Complete the practice tasks and update the daily learning log.

> The numbering follows the training roadmap. The repository retains the module numbering used for the learning drive.
