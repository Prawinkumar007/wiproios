# 08 — Practice Tasks

Track hands-on tasks and mark each item as you complete it.

## Swift fundamentals
- [ ] Declare constants and variables using let and var.
- [ ] Practice arithmetic, comparison, and logical operators.
- [ ] Write a function with parameters and a return value.

## Collections
- [ ] Create and modify an Array.
- [ ] Remove duplicates using a Set.
- [ ] Insert, update, and read Dictionary values.

## Core language
- [ ] Create an enum, struct, and class.
- [ ] Safely unwrap an Optional.
- [ ] Demonstrate a weak reference.
- [ ] Use map, filter, and reduce.
- [ ] Define and conform to a protocol.
- [ ] Write a generic function.
- [ ] Throw and handle a custom error.
