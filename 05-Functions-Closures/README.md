# 05 — Functions and Closures

## Topics
- Function declarations, parameters, argument labels, and return values
- Default and variadic parameters
- Functions as values
- Closure expressions and trailing closure syntax
- Capturing values
- Higher-order functions: map, filter, reduce, sorted

## Practice tasks
1. Write a function that calculates a course completion percentage.
2. Sort a list of tasks by title using a closure.
3. Use filter to select incomplete tasks and reduce to count or total values.

## Outcome
Write reusable behavior and use closures to express collection transformations.
