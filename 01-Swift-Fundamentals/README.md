# 01 — Swift Fundamentals

## Topics
- Swift introduction, features, syntax, and basic data types
- Variables (`var`) and constants (`let`)
- Arithmetic, comparison, logical, and assignment operators
- Expressions, string interpolation, and type inference
- Xcode, Command Line Tools, and iOS Simulator setup

## Practice
Run `SwiftFundamentals.swift`. Identify each constant, variable, operator, and expression, then change the sample values and observe the output.

## Outcome
Understand the Swift language basics needed for the remaining iOS modules.
