# 03 — Enums, Structs, and Classes

## Topics
- Enumerations and associated values
- Structures as value types
- Classes as reference types
- Stored and computed properties
- Initializers, methods, and mutating methods
- Value semantics versus reference semantics

## Practice tasks
1. Create an enum for a task's status.
2. Create a Student struct with properties and a method.
3. Create a Course class and compare two references to the same instance.
4. Add a computed property to a model.

## Outcome
Model application data using suitable Swift types.
