# 04 — Optionals and ARC

## Topics
- Optional types and nil
- Optional binding with if let and guard let
- Optional chaining and nil-coalescing
- Forced unwrapping and when to avoid it
- Automatic Reference Counting (ARC)
- Strong, weak, and unowned references
- Retain cycles and deinitialization

## Practice tasks
1. Write a safe function that accepts an optional String.
2. Model a parent-child reference relationship with a weak back-reference.
3. Explain why two strong references can create a retain cycle.

## Outcome
Handle missing values safely and understand object lifetime in class-based models.
