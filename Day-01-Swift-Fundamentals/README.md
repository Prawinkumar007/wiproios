# Day 01 — Swift Fundamentals

This folder records the Swift and iOS development topics covered in the Wipro iOS learning drive.

## Topics covered

1. **Prerequisite and infrastructure setup**
   - Mac / macOS development environment
   - Xcode
   - Xcode Command Line Tools
   - iOS Simulator

2. **Swift fundamentals**
   - Introduction to Swift, features, and syntax
   - Variables and constants
   - Operators and expressions

3. **Swift collections**
   - Arrays
   - Sets
   - Dictionaries

4. **Enumerations, structures, and classes**
   - Defining and using enumerations
   - Value types (structures)
   - Reference types (classes)

5. **Optionals and optional handling**
   - Optional values
   - Optional binding
   - Nil-coalescing operator

6. **Automatic Reference Counting (ARC) and memory management**
   - Strong and weak references
   - Reference cycles
   - Object lifetime

7. **Functions**
   - Parameters and argument labels
   - Return types
   - Reusable functions

8. **Closures and higher-order functions**
   - Closure expressions
   - map, filter, reduce, and sorted

9. **Protocols and extensions**
   - Protocol requirements and conformance
   - Extending existing types

10. **Generics and error handling**
    - Generic functions
    - Defining and throwing errors
    - Handling errors with do-catch

## Practice file

See SwiftFundamentals.swift for small runnable examples of the language concepts above.

## Run

Open the Swift file in an Xcode macOS Command Line Tool project or a Swift Playground and run it.
