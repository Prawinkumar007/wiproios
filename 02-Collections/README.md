# 02 — Swift Collections

## Topics
- Arrays: ordered collections, indexing, insertion, removal, iteration
- Sets: unique values, membership, union, intersection, subtraction
- Dictionaries: key-value storage, lookup, update, removal
- Collection iteration and common methods

## Practice tasks
1. Create an array of five iOS topics and print them with their indexes.
2. Remove a duplicate value by converting an array to a Set.
3. Build a dictionary of topic names and completion percentages.
4. Use map, filter, and sorted on a collection.

## Outcome
Choose the appropriate collection for ordered, unique, and keyed data.
